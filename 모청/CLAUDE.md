# 모바일 청첩장 프로젝트

허영민 · 김나희 결혼식 모바일 청첩장. `index.html` 하나로 동작하는 정적 페이지.

## 핵심 정보

- **신랑**: 허영민 (아버지 허호진 · 어머니 윤정은)
- **신부**: 김나희 (아버지 김환규 · 어머니 조윤희)
- **일시**: 2026년 11월 8일 일요일 오후 3시 30분
- **장소**: 서울시립대학교 자작마루 (서울특별시 동대문구 서울시립대로 163, 서울시립대학교 내 · 법학관 맞은편)

## 파일 구조

- `index.html` — 청첩장 본체 (모든 문구·연락처·계좌 정보는 파일 상단 `CONFIG` 객체에서 관리)
- `INFO.md` — 계좌번호, 전화번호, 교통편 등 실제 값을 채워 넣는 작업용 문서. 여기 채운 값을 `index.html`의 `CONFIG` 객체에 옮겨 반영한다.
- `images/main.jpg` — 커버(상단) 사진. 웹용으로 리사이즈·압축된 버전 (실제 배포/git에 포함되는 파일)
- `images/*` (main.jpg 제외) — 포토 갤러리에 들어가는 사진들. 마찬가지로 웹 최적화본
- `images-original/` — 카메라 원본 고해상도 사진 백업 (git에는 올리지 않음, `.gitignore` 처리됨). 사진을 교체/추가하려면 여기에 원본을 넣고 `optimize_images.py`를 실행
- `optimize_images.py` — `images-original/`의 원본을 리사이즈(긴 변 1800~2200px)·압축(quality 82)·EXIF 제거해서 `images/`에 저장하는 재사용 가능한 스크립트. `python optimize_images.py`로 실행
- `샘플1/`, `샘플2/` — 레퍼런스로 저장해둔 실제 모바일 청첩장(살롱드레터, 바른손카드) HTML. 디자인/기능 참고용이며 배포 대상 아님 (다른 실제 커플의 개인정보가 포함돼 있어 `.gitignore` 처리됨)
- `보정본/`, `대만/` — 원본 사진 백업. 갤러리는 `images/` 안의 사진만 사용 (`.gitignore` 처리됨)

## 디자인 톤

모던 미니멀 (샘플2/바른손카드 스타일 참고). 화이트/아이보리 배경, 절제된 세리프+산세리프 조합, 얇은 구분선, 여백 중심. 화려한 장식·리스 없음.

## 포함/제외 기능 (사용자 확정)

- ❌ RSVP(참석 여부 전달) 섹션 — 없음. 정적 사이트라 백엔드 없이는 응답을 못 받으므로 아예 제외
- ✅ 계좌번호("마음 전하실 곳") — 버튼을 눌러야 펼쳐지는 토글 방식
- ❌ 축하화환 보내기 섹션 — 없음 (연결할 화환 업체가 없어서 제외, 필요시 나중에 추가)
- ✅ 갤러리 — `images/` 폴더 사진 전부 (main.jpg 제외), 그리드 + 라이트박스
- ✅ 오시는 길 — 카카오맵/네이버지도/티맵 검색 링크 버튼 (좌표 임베드 아님)
- ✅ 링크 복사 공유 버튼 (카카오톡 공유는 API 키 없이는 불가하므로 URL 복사로 대체. 나중에 카카오 JS 키 발급 시 `index.html` 내 주석 처리된 자리에 추가 가능)

## 배포

이 저장소(`pirant82/links`, GitHub Pages)는 루트에 여러 개별 페이지를 두고 `index.html`이 허브 역할을 하는 구조. 청첩장은 `모청/index.html`로 접근 가능하며, 필요하면 루트 `index.html`의 카드 그리드에 링크를 추가해둔다.

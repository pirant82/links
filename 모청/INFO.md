# 청첩장 정보 입력지

여기에 값을 채운 뒤, `index.html` 맨 위 `const CONFIG = { ... }` 블록의 같은 항목에 그대로 옮겨 넣으면 청첩장에 반영됩니다. (정적 페이지라 자동 연동은 안 되고, 값을 복사해서 옮겨야 해요.)

미입력 항목은 `index.html`에 `"직접 입력해주세요"` 같은 placeholder로 표시되어 있습니다.

---

## 1. 계좌번호 (마음 전하실 곳)

| 구분 | 이름 | 은행 | 계좌번호 | 비고 |
|---|---|---|---|---|
| 신랑 | 허영민 | 우리은행 | 1002-455-194604 | 입력됨 |
| 신랑 아버지 | 허호진 | | | 미입력 |
| 신랑 어머니 | 윤정은 | | | 미입력 |
| 신부 | 김나희 | | | 미입력 |
| 신부 아버지 | 김환규 | | | 미입력 |
| 신부 어머니 | 조윤희 | | | 미입력 |

카카오뱅크 등 송금 링크(예: `kakaobank://...` 또는 계좌 QR)를 쓰고 싶다면 여기에 링크도 같이 적어주세요.

---

## 2. 연락처 (전화/문자 버튼용)

| 구분 | 이름 | 전화번호 (010-0000-0000 형식) |
|---|---|---|
| 신랑 | 허영민 | |
| 신부 | 김나희 | |
| 신랑 아버지 | 허호진 | |
| 신랑 어머니 | 윤정은 | |
| 신부 아버지 | 김환규 | |
| 신부 어머니 | 조윤희 | |

전화번호를 넣지 않은 사람은 청첩장에서 해당 전화/문자 버튼이 자동으로 숨겨집니다.

---

## 3. 오시는 길 / 교통 안내

- **장소**: 서울시립대학교 자작마루
- **주소**: 서울특별시 동대문구 서울시립대로 163 (전농동 90, 서울시립대학교 내 · 법학관 맞은편) — 웹 검색 기준, **정확한 주소는 예식장에 문의해 확인 후 수정 권장**
- **지하철**: (예: 1호선 청량리역 X번 출구, 셔틀버스 운행 여부 등 — 미입력)
- **버스**: (예: 간선/지선 버스 번호, 정류장명 — 미입력)
- **주차**: (예: 교내 주차 가능 대수, 주차 등록 방법 — 미입력)
- **예식장 전화번호**: (미입력)

---

## 4. 인사말 문구

`index.html`의 `CONFIG.greeting` 배열에 기본 문구가 들어가 있습니다. 원하는 문구로 자유롭게 교체하세요 (부모님 성함 순서, 계절 인사 등 취향껏).

---

## 5. 갤러리 사진 순서

기본값은 `images/` 폴더의 파일명 기준(자동 정렬)입니다. 특정 사진을 맨 앞에 배치하고 싶으면 `index.html`의 `CONFIG.gallery` 배열 순서를 직접 바꾸면 됩니다.

---

## 6. 알아두실 것 — DSCF6932.jpg 원본 백업 손상

이미지 최적화 작업 중 컴퓨터가 예기치 않게 재부팅되면서 `images-original/DSCF6932.jpg`(카메라 원본 백업)가 손상됐습니다. **웹사이트에 쓰이는 `images/DSCF6932.jpg`(압축본)는 정상이라 청첩장에는 문제없이 나옵니다.** 다만 향후 재압축이 필요할 경우를 대비한 고해상도 원본은 로컬에 없는 상태입니다.

OneDrive에 자동 백업되어 있을 가능성이 높으니, 원본이 필요하면 [onedrive.com](https://onedrive.com)에서 해당 파일을 찾아 "버전 기록"으로 이전 버전을 복구하시면 됩니다.

## 7. 나중에 추가할 수 있는 것들 (지금은 제외)

- **RSVP(참석 여부 전달)**: 구글폼을 만들어서 링크만 넘겨주면 버튼 하나로 쉽게 추가 가능
- **축하화환 보내기**: 이용할 화환 업체(카카오톡 선물하기, 종근화원 등)를 알려주면 섹션 추가 가능
- **카카오톡 공유 시 썸네일 커스텀**: [Kakao Developers](https://developers.kakao.com)에서 앱 등록 후 JS 키 발급하면, `index.html` 내 `<!-- KAKAO_SHARE_KEY -->` 주석 자리에 넣어서 활성화 가능
